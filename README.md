# Dashboard Comercial de Ventas

Dashboard web hecho con Python + Streamlit.

## Ejecutar en local
1. Abre CMD dentro de esta carpeta.
2. `pip install -r requirements.txt`
3. `streamlit run app.py`
4. Abre http://localhost:8501

## Publicar (para que el gerente solo abra un enlace)
1. Sube esta carpeta a un repositorio de GitHub.
2. Entra a https://share.streamlit.io, conecta GitHub y elige `app.py`.
3. Comparte el enlace público generado.

## Estructura
- app.py: aplicación
- ventas.csv: datos
- requirements.txt: librerías
- .streamlit/config.toml: tema de colores
